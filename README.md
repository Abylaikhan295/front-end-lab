Part 1. Media Queries

Task 0. Responsive Typography
Created a basic HTML structure with headings (`<h2>`, `<h3>`) and body text (`<p>`). Applied CSS media queries (`@media`) to dynamically scale typography down for tablet and mobile viewports.

Task 1. Responsive Layout with Media Queries
Designed a 3-box container (`.media-container`) using pure CSS Flexbox and media queries (without Bootstrap grid). 
  Desktop: All 3 boxes sit horizontally in a row.
  Tablet: Displays 2 boxes in a row.
  Mobile: Displays all 3 boxes stacked vertically (100% width).

Work Process Summary

In this project, I combined custom CSS media queries with Bootstrap 5 to build a modern, fully responsive web application. I set up breakpoints at 1270px, 768px, and 568px to ensure text and layouts seamlessly adapt across desktop, tablet, and mobile devices. Leveraging Bootstrap's 12-column grid and interactive navbar, I created a clean portfolio page complete with mobile-specific element visibility. Finally, I tested the layout across various viewports, organized the code, and published everything directly to GitHub.
